# 03 — Installed Skills & Role-to-Skill Mapping

> Use this reference during **Step 2 (Recommend Approach & Skills)** and throughout Multi-Agent execution.

---

## 1. Installed Skills Catalog

### Code & Architecture
- **`ponytail` (use `lite` mode by default):** Prevents over-engineering, dead wrappers, and bloat; enforces smallest coherent solution.
- **`ponytail-review` / `ponytail-audit`:** Logic, safety, load, test coverage, and bloat reviews.
- **`modern-web-guidance`:** Mandatory check for modern HTML/CSS/DOM/web API best practices (accessibility, forms, dialogs, performance, security).

### UI / UX Design & Visual Craft
- **`interface-design`:** Craft-first product UI for dashboards, SaaS apps, tools, and data interfaces (hierarchy, tokens, states).
- **`hallmark`:** High-craft design direction for new websites/pages that look designed, not AI-generated.
- **`anti-slop-craft`:** Eliminates generic AI clichés (purple gradients, filler copy, over-engineered wrappers).
- **`ui-ux-pro-max` & `uxui-pro-2027`:** Design system intelligence, palettes, typography pairings, and modern spatial/interaction patterns.
- **`mobbin` (`search`, `redesign-screen`):** Real-world shipped app references for benchmarking flows and screens.

### Writing & Interface Copy
- **`ux-writing` & `better-writing`:** Purposeful, concise, accessible microcopy (buttons, labels, errors, empty states, confirmations).
- **`copy-editing` & `copywriting`:** Clear headlines, positioning, and tightening existing copy without AI tells.
- **`humanizer`:** Rewrites AI-sounding prose so it reads naturally (especially useful for natural bilingual EN/TH copy).
